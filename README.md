# Pipeline QIIME 2 - Análisis de Microbioma
Este repositorio contiene los metadatos y las visualizaciones del análisis de amplicones 16S rRNA utilizando QIIME 2 (versión rachis-qiime2-2026.10).

## Archivos incluidos:
- `manifest.tsv`: Archivo de entrada de secuencias.
- `sample-metadata.tsv`: Metadatos de las muestras.
- `demux-summary.qzv`: Reporte de calidad de las secuencias.
- `taxa-bar-plots.qzv`: Gráfico de barras de la composición taxonómica.
